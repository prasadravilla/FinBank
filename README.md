# FinBank

FinBank is a full-stack digital banking and transaction monitoring application.

## Project Status

🚧 Under Development

## Technology Stack

### Frontend
- React

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### Authentication
- JWT
- bcrypt

## Planned Features

- User registration and login
- Bank account management
- Deposit and withdrawal
- Money transfer
- Transaction history
- Admin dashboard
- Role-based access control
- Fraud detection
- Audit logging
- Scheduled payments
- Notifications
- PDF bank statements
